# Тапер (Tapper)

Android-приложение для автоматических нажатий в выбранной области экрана.

## Возможности
- Плавающая панель управления поверх других приложений (через Accessibility overlay).
- Выбор прямоугольной области на экране.
- Случайное нажатие внутри выбранной области.
- Частота от 1 до 10 нажатий в секунду.
- Перетаскивание панели, запуск и остановка без закрытия TikTok.
- Для работы требуется вручную включить службу «Тапер» в настройках специальных возможностей Android.

## Сборка APK
GitHub Actions автоматически собирает Debug APK при каждом push в `main` и при запуске workflow вручную.

1. Откройте вкладку **Actions** репозитория.
2. Выберите **Android APK**.
3. Откройте завершившийся запуск.
4. Скачайте артефакт **tapper-debug-apk**.

Путь внутри артефакта: `app/build/outputs/apk/debug/app-debug.apk`.

## Сборка локально
Требуются JDK 17 и Gradle 8.7:
```bash
gradle assembleDebug
```

## Разрешения и ограничения
Приложение использует Android AccessibilityService для отправки жестов. Пользователь должен сам включить службу в системных настройках. Не используйте автоматические нажатия для обхода защит, накрутки активности или нарушения правил приложений. Поведение службы и доступность жестов зависят от версии Android и прошивки устройства.
